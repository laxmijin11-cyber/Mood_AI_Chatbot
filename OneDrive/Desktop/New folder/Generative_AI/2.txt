# 🤖 Mood Based AI Chatbot

A multi-personality AI chatbot built with **Streamlit** and **LangChain**, powered by **Mistral AI**. 
Users can switch between **Angry**, **Funny**, and **Sad** personalities to experience completely different conversational styles.

```bash

```bash
python -m venv venv
```

### 3. Activate the Environment

**Windows:**
```bash

```

**Mac/Linux:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Configure API Key
Create a `.env` file in the root folder and add:
```text
MISTRAL_API_KEY=your_api_key_here
```

### 6. Run the Application
```bash
python -m streamlit run app.py
```

## 🧠 How It Works

1. **Personality Selection:** The user selects a mood (Angry, Funny, or Sad) via `st.radio`.
2. **System Prompt:** The app sets a `SystemMessage` to define the AI's personality.
3. **User Input:** The user's message is added to the chat history as a `HumanMessage`.
4. **AI Response:** The `ChatMistralAI` model is invoked with the full conversation history.
5. **Output:** The AI's response is stored as an `AIMessage` and displayed in the chat bubble.
6. **Reset:** The `Reset Chat` button clears the session state and reruns the app.
